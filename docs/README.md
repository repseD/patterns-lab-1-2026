
Описание решения
adapters/digital_clock_adapter.py - реализует интерфейс BaseDigitalClock и через композицию
обёртывает готовый  AnalogClock . Назначение - совместить несовместимые интерфейсы:

set_date_time(datetime)  переводит время в углы стрелок: часы →  (hour % 12) * 30,
минуты и секунды*6 , выставляет  AM/PM  (полночь - AM, полдень - PM);

get_date_time()  выполняет обратное преобразование углов и  AM/PM  в  datetime 
(для PM добавляется 12 часов).

facades/clock_facade.py - скрывает подсистему (адаптер,  ClockFormatter ,  ClockHistory ) за интерфейсом:

set_date_time(date) - установить время (и записать в историю);
get_date_time() - получить  datetime;
get_formatted() - форматированная строка;
get_history() - история изменений.

Фасад не содержит бизнес-логику и делегирует вызовы компонентам подсистемы.


Результат - код работает только с фасадом и не знает ни об  AnalogClock, ни о сервисах.
